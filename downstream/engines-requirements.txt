# Engine packages for tests/engines.py, which executes translated SQL for real.
# Install with: pip install -r downstream/engines-requirements.txt
# Not part of the default install or of the dev extra. Engines without Python
# 3.9 wheels are gated by marker; tests import every engine lazily, so a missing
# package skips (or fails under BENCHBOX_ENGINES_REQUIRED) instead of breaking
# collection.
#
# Version policy: the in-process engines are held to the release series BenchBox
# locks (BenchBox uv.lock) and supports (BenchBox pyproject.toml), so the tests
# execute SQL on the engines users run. A newer major (DuckDB 2.0 removed the
# lambda arrow, DataFusion 55, chDB 4.4) is not tested until BenchBox supports
# it. Raise a pin together with BenchBox's lock; each job prints the installed
# versions.
duckdb>=1.5,<2
datafusion>=54,<55; python_version >= '3.10'
chdb>=4.1,<4.2; python_version >= '3.10'
pyspark>=4.2,<4.3; python_version >= '3.10'
psycopg[binary]>=3.1
trino>=0.330
pymysql>=1.1
